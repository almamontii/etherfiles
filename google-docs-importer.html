📄 Importar Artículo desde Google Docs

📋 Cómo usar:

Opción 1: Link de Google Docs

  1. Comparte tu Google Doc como "Cualquiera con el link puede ver"
  2. Copia el link del documento
  3. Pégalo en el campo "Link de Google Docs"
  4. Haz clic en "Importar desde Link"

Opción 2: Copiar y Pegar

  1. Crea tu artículo en Google Docs con este formato:
TÍTULO: [Nombre del artículo] DESCRIPCIÓN: [Tu descripción aquí] IMAGEN: [nombre.jpg o URL] (opcional) SPOTIFY: [URL de playlist de Spotify] TAMAÑO: small|medium|large|tall (opcional, default: medium) --- Si quieres crear múltiples artículos, separa cada uno con "---" en una línea nueva.
  1. Copia todo el contenido de tu Google Doc
  2. Pégalo en el campo de abajo
  3. Haz clic en "Procesar y Agregar"
Asegúrate de que el documento esté compartido como "Cualquiera con el link puede ver"
